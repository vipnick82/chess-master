# Chess Master

Личен шахматен треньор на български: кратки уроци, пъзели по слабите места, дебютен репертоар, игра срещу Stockfish с треньор и разбор на партиите. Работи като приложение на телефона и без интернет.

**Отвори:** https://vipnick82.github.io/chess-master/

## Инсталиране на телефона

**iPhone:** отвори линка в **Safari** → бутона „Сподели“ (квадратчето със стрелка) → **„Добави към началния екран“**.

**Android:** отвори линка в **Chrome** → бутона **„Инсталирай“** (или менюто ⋮ → „Добави към началния екран“).

След това приложението се отваря на цял екран от собствена иконка и работи и офлайн. Новите версии идват сами: при отваряне се показва бутон „Обнови“.

## Прогрес

Прогресът (ниво, уроци, рейтинг, партии) се пази на самото устройство. За да го преместиш, например от версията в Claude към телефона: „Настройки“ → „Пренеси прогреса“ → „Копирай прогреса“, после в другата версия поставяш кода и натискаш „Зареди прогреса“.

## Как се обновява

Кодът е общ за приложението в GitHub Pages и за страницата в Claude.

```
src/page.html          интерфейс и стилове
*.js                   логиката на приложението
tools/build.py         сглобява index.html, sw.js и dist-claude/index.html
```

След промяна:

```bash
python3 tools/build.py
```

След това се прави commit и push към `main`. GitHub Pages публикува новата версия за 1-2 минути.

## Файлове

| Файл | Какво е |
|---|---|
| `index.html`, `sw.js` | генерирани от `tools/build.py`, не се редактират на ръка |
| `manifest.webmanifest`, `pwa.js`, `icons/` | инсталиране като приложение и работа офлайн |
| `data.js`, `lessons.js` | дебютни курсове, учебен път от 20 урока |
| `core.js` | състояние, дъска, Stockfish, анализ на партии и навици |
| `tasks.js`, `smart.js` | пъзели, упражнения, адаптивен избор по слабите места, треньор |
| `views.js`, `extras.js`, `play.js` | екраните на приложението |
| `assets.js`, `pieces.js` | звуци и комплекти фигури |
| `puzzles.json` | 7 559 тактически пъзела |
